# Результаты для организаторов

Формат - «CQA Student Guide Appendix: Как сдать результаты», JSON 1.0.

| Файл | Набор |
|---|---|
| `dev/results.json` | DEV: 60 чатов + 5 звонков (65 записей) |
| `prod/results.json` | контрольный набор: ровно 10 записей, включая ошибки |

Файлы собираются кодом из базы CQA (`backend/cqa/results_export.py`) и перед записью проверяются по формату 1.0:
все 8 критериев, типы значений, `evidence_turns` с 1 по исходному транскрипту, `final_score` 0-100, без повторов ID,
неоценённые диалоги - `status: "error"` с причиной.

## Как собрать (сервер CQA запущен)

```bash
cd backend
../.venv/bin/python -m cqa.submit --group DEV --set dev
../.venv/bin/python -m cqa.submit --group <group_id> --set prod --expect 10 --push
```

Команда загружает набор, оценивает его активным чек-листом, выгружает и проверяет файл, с `--push` коммитит и пушит.
Без push результат не засчитывается.

То же из интерфейса: **Диалоги** → меню **Экспорт** → **Результаты в формате JSON 1.0**.
