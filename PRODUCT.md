# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

QA-супервайзеры контакт-центра Freedom Broker. Работают в инструменте весь день: разбирают десятки диалогов операторов (чаты и звонки на RU, KZ, EN), проверяют автоматическую оценку ИИ по чек-листу, подают и рассматривают апелляции, правят чек-лист. Вторая аудитория: жюри хакатона, которое смотрит 5-минутное демо, но оптимизируем под ежедневную работу супервайзера.

## Product Purpose

CQA (Conversation Quality Analytics) оценивает работу оператора по настраиваемому чек-листу: по каждому критерию ответ, баллы, вес, обоснование и реплика-доказательство; итог с перераспределением веса при N/A и отдельным флагом грубой ошибки. Поддерживает апелляцию, решение проверяющего с пересчётом итога и версии чек-листа. Успех: супервайзер быстро понимает, почему поставлена оценка, проверяет её по тексту диалога и принимает решение.

## Positioning

Оценка, которую можно проверить: каждое утверждение ИИ привязано к конкретной реплике или фрагменту записи звонка, а итог считается кодом строго по правилам чек-листа. Несколько независимых прогонов модели показывают, где ИИ уверен, а где решение стоит перепроверить.

## Operating Context

Длинные смены за десктопным монитором. Рабочий цикл: список диалогов, карточка (транскрипт рядом с оценкой), переход по ссылке на реплику, прослушивание фрагмента звонка, апелляция, решение. Интерфейс в будущем встраивается в Microsoft Dynamics 365 как HTML-веб-ресурс.

## Capabilities and Constraints

- Чистые HTML/CSS/ES-модули без сборки и без внешних CDN, шрифтов и библиотек (требование встраивания в Dynamics 365).
- Каждый экран монтируется в любой контейнер (`mount(container, ctx)`), базовый адрес API в `frontend/config.js`.
- Контракт API: `docs/API.md`. Интерфейс только на русском.
- Данные диалогов содержат стрелки и тире в собственном тексте клиентов и операторов (например «Меню → Пополнить»): это данные, их не трогаем.

## Brand Commitments

- Фирменный стиль Freedom обязателен: узнаваемый тёмно-зелёный Freedom и общий тон бренда (по материалам организаторов: глубокий зелёный фон шапки, светло-зелёные акценты).
- Тексты интерфейса и ответы ИИ без длинных тире и декоративных стрелок; сухой, деловой язык без канцелярита и пояснений ради пояснений.

## Evidence on Hand

- Реальные данные DEV: 65 диалогов (`data/dev.json`), записи звонков через API организаторов.
- Контрольная разметка команды `eval/reference_dev.json` (не официальный эталон).
- Чек-лист организаторов: `backend/cqa/default_checklist.json`.

## Product Principles

1. Доказательство рядом с выводом: оценка всегда показана вместе с репликой, на которой она основана.
2. Плотность для ежедневной работы важнее декора: больше смысла на экран, меньше рамок.
3. Решение человека главнее ИИ: исходная оценка, решение и финальный итог всегда видны раздельно.
4. Честность о неуверенности: расхождение прогонов модели показывается, а не прячется.
